# RECOMENDAÇÕES POR PAPEL — STAR OS

## 1. Finalidade

As recomendações por papel adaptam a leitura operacional conforme o
usuário: vendedor, gestor, sócio ou consultor — como um sistema
especialista determinístico, sem IA.

## 2. O que usa

- `STATUS`.
- `CURVA`.
- `MESES_SEM_COMPRA`.
- `EROSAO STAR`.
- `MEDIA LP`.
- `MEDIA CP`.
- `NIVEL_PRIORIDADE`.
- `TIPO_PRIORIDADE`.
- Hipóteses Operacionais, quando disponíveis.

## 3. O que entrega

- Foco operacional.
- Recomendações para vendedor.
- Recomendações para gestor.
- Recomendações para sócio.
- Recomendações para consultor.
- Observações de cautela.

## 4. O que não faz

- Não usa IA.
- Não consome token.
- Não altera Motor STAR.
- Não altera cálculo.
- Não altera status.
- Não altera curva.
- Não altera recência.
- Não altera erosão.
- Não cria plano de ação.
- Não cria tarefa.
- Não envia mensagem.
- Não automatiza execução.
- Não substitui diagnóstico humano.
- Não substitui gestor.

## 5. Princípio metodológico

- Recomendações são orientações iniciais.
- Recomendação não é execução.
- Evidência vem antes da intervenção.
- Cada papel precisa de nível diferente de leitura.
- Vendedor precisa de clareza operacional.
- Gestor precisa de controle e acompanhamento.
- Sócio precisa de leitura executiva de risco.
- Consultor precisa de leitura sistêmica e diagnóstica.

## 6. Limites

- As recomendações são determinísticas.
- Casos ambíguos exigem validação humana.
- Registro de ação e governança ficam para sprints futuras.
- IA poderá ser usada no futuro apenas como camada assistiva, não como
  substituta da lógica STAR.
