# HIPÓTESES OPERACIONAIS — STAR OS

## 1. Finalidade

As hipóteses operacionais ajudam a investigar possíveis causas por trás de
status, erosão, recência, curva e prioridade — funcionando como um sistema
especialista determinístico, sem IA.

## 2. O que usa

- `STATUS`.
- `CURVA`.
- `MESES_SEM_COMPRA`.
- `EROSAO STAR`.
- `MEDIA LP`.
- `MEDIA CP`.
- `NIVEL_PRIORIDADE`.
- `TIPO_PRIORIDADE`.

## 3. O que entrega

- Hipóteses por status.
- Hipóteses por sinais.
- Perguntas de validação.
- Alertas de investigação.
- Resumo de hipótese.

## 4. O que não faz

- Não usa IA.
- Não consome token.
- Não altera Motor STAR.
- Não altera cálculo.
- Não altera status.
- Não altera curva.
- Não altera recência.
- Não altera erosão.
- Não cria recomendação completa.
- Não cria plano de ação.
- Não substitui diagnóstico humano.

## 5. Princípio metodológico

- Hipótese não é conclusão.
- Hipótese precisa ser validada por evidência.
- Pergunta vem antes da recomendação.
- O sistema deve apoiar a investigação, não encerrar o diagnóstico sozinho.

## 6. Limites

- As hipóteses são determinísticas.
- Casos ambíguos exigem validação humana.
- IA poderá ser usada no futuro apenas como camada assistiva, não como
  substituta da lógica STAR.
