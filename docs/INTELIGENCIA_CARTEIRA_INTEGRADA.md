# INTELIGÊNCIA DE CARTEIRA INTEGRADA — STAR OS

## 1. Finalidade

A Inteligência de Carteira existe para transformar a Matriz STAR em
prioridade operacional, leitura de risco, orientação comercial e governança
de carteira.

Deixando claro:

- Não é dashboard paralelo.
- Não é substituto da Matriz STAR.
- Não é IA generativa.
- Não altera o Motor STAR.
- Não altera regras de cálculo.
- É uma camada de interpretação e priorização sobre a base já processada.

## 2. Problema estrutural que resolve

Depois que a Matriz STAR é gerada, o usuário ainda precisa saber:

- quais clientes atacar primeiro;
- quais clientes estão em risco;
- quais clientes devem ser preservados;
- quais clientes exigem reativação;
- quais clientes exigem diagnóstico;
- qual ação operacional deve ser tomada;
- por qual papel: vendedor, gestor, sócio ou consultor.

Hoje a Matriz STAR calcula corretamente os dados, mas não organiza
prioridade nem orienta ação por papel.

- Hipóteses operacionais por cliente.
- Recomendações determinísticas por status.

- Ação sugerida com objetivo.
- Indicação de prazo.
- Indicação de responsável.
- Organização para ritual comercial.
- Preparação para governança semanal.

## 5. O que ela não deve fazer

- Não recalcular a Matriz STAR.
- Não alterar status STAR.
- Não alterar curva ABC.
- Não alterar recência.
- Não alterar erosão.
- Não substituir o vendedor.
- Não substituir o gestor.
- Não criar forecast.
- Não criar IA.
- Não criar automação.
- Não gerar recomendação sem base nos dados STAR.
- Não virar dashboard paralelo.

## 6. Princípios de integração

- Reutilizar a Matriz STAR como entrada.
- Reutilizar os campos já calculados.
- Reutilizar o fluxo atual antes de criar nova tela.
- Evoluir por módulos pequenos.
- Preservar o Motor STAR.
- Separar cálculo de interpretação.
- Separar interpretação de execução.
- Separar execução de governança.
- Manter Excel-first nesta fase.
